# BabyMemo 安装指南

## 系统要求

### 硬件要求
- CPU: 1.6 GHz 或更高
- 内存: 4 GB 或更多
- 存储空间: 至少 500 MB 可用空间

### 软件要求
- Windows: Windows 10 或更高版本
- macOS: macOS 10.15 或更高版本
- Linux: Ubuntu 18.04 或更高版本
- Node.js: v18.0.0 或更高版本
- Bun: 最新版本

## 安装步骤

### 方法一：使用源码安装

1. **克隆项目代码**
   ```bash
   git clone https://github.com/yourusername/babymemo.git
   cd babymemo
   ```

2. **安装依赖**
   ```bash
   bun install
   ```

3. **启动开发服务器**
   ```bash
   bun dev
   ```

4. **访问应用**
   打开浏览器，访问 `http://localhost:3000`

### 方法二：使用桌面应用

1. **下载安装包**
   - Windows: `BabyMemo-Setup.exe`
   - macOS: `BabyMemo.dmg`
   - Linux: `BabyMemo.AppImage`

2. **安装应用**
   - Windows: 双击安装包，按照提示完成安装
   - macOS: 双击 `.dmg` 文件，将应用拖入 Applications 文件夹
   - Linux: 右键点击 AppImage 文件，选择 "属性"，勾选 "允许作为程序执行"，然后双击运行

3. **运行应用**
   安装完成后，从桌面或应用菜单启动 BabyMemo

## 首次使用

1. **注册账号**
   - 打开应用，点击 "注册" 按钮
   - 输入用户名、密码和姓名
   - 点击 "注册" 按钮完成注册

2. **登录系统**
   - 输入注册时使用的用户名和密码
   - 点击 "登录" 按钮进入系统

3. **添加宝宝信息**
   - 登录后，点击左侧导航栏的 "宝宝管理"
   - 点击 "添加宝宝" 按钮
   - 填写宝宝的姓名、出生日期、性别等信息
   - 点击 "保存" 按钮

4. **开始记录**
   - 照片墙：上传和管理宝宝的照片
   - 创意日记：记录宝宝的成长故事
   - 创意日历：标记重要的成长日期
   - 时光轴：记录宝宝的成长里程碑
   - 成长指标：追踪宝宝的身高、体重等指标
   - 视频管理：上传和管理宝宝的视频

## 数据备份与恢复

### 导出数据
1. 点击左侧导航栏的 "设置"
2. 点击 "数据备份"
3. 选择导出格式（JSON 或 CSV）
4. 点击 "导出" 按钮，保存备份文件

### 导入数据
1. 点击左侧导航栏的 "设置"
2. 点击 "数据恢复"
3. 选择之前导出的备份文件
4. 点击 "导入" 按钮，完成数据恢复

## 常见问题

### 1. 无法启动应用
- 检查是否安装了 Node.js 和 Bun
- 检查端口 3000 是否已被占用
- 查看终端输出的错误信息

### 2. 数据丢失
- 定期备份数据
- 确保应用正常关闭，避免强制退出

### 3. 照片上传失败
- 检查文件大小是否超过限制
- 检查网络连接
- 检查存储空间是否充足

### 4. 应用卡顿
- 清理浏览器缓存
- 关闭不必要的标签页和应用
- 检查系统资源使用情况
