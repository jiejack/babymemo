# BabyMemo 使用指南

## 🎯 系统概述

BabyMemo 是一个专为父母设计的宝宝成长记录系统，帮助您记录和管理宝宝的成长历程。本指南将详细介绍系统的使用方法。

## 🔐 登录系统

### 访问系统

1. 打开浏览器，访问：http://localhost:3000
2. 您将看到登录页面

### 登录方式

**演示账号**：
- 用户名：demo
- 密码：demo123

**登录步骤**：
1. 在登录页面输入用户名和密码
2. 点击「登录」按钮
3. 系统验证成功后，自动跳转到仪表盘页面

### 注册新用户

1. 在登录页面点击「注册」按钮
2. 切换到注册表单
3. 输入用户名、密码和姓名
4. 点击「注册」按钮
5. 注册成功后，系统自动登录并跳转到仪表盘

## 📊 仪表盘

仪表盘是系统的主页面，展示了宝宝成长的概览信息。

### 功能区域

1. **欢迎信息**：显示欢迎语和用户名称
2. **快速操作**：
   - 上传照片
   - 写日记
3. **最近记忆**：
   - 最近照片：展示最近上传的宝宝照片
   - 最近日记：展示最近写的日记
   - 最近里程碑：展示最近添加的成长里程碑
4. **成长指标**：展示宝宝的成长数据概览

### 导航菜单

顶部导航菜单包含以下功能入口：
- 照片墙
- 创意日记
- 创意日历
- 时光轴
- 宝宝管理
- 成长指标
- 视频管理
- 设置

## 📷 照片墙

### 功能说明

照片墙用于存储和管理宝宝的照片，记录宝宝成长的美好瞬间。

### 使用方法

1. **查看照片**：进入照片墙页面，浏览已有的宝宝照片
2. **添加照片**：
   - 点击「添加演示照片」按钮
   - 系统会自动添加一张演示照片
3. **管理照片**：
   - 点击照片下方的「编辑」按钮，修改照片信息
   - 点击「删除」按钮，删除照片

## 📝 创意日记

### 功能说明

创意日记用于记录宝宝的成长故事，写下宝宝的日常趣事和重要事件。

### 使用方法

1. **查看日记**：进入创意日记页面，浏览已有的日记列表
2. **添加日记**：
   - 点击「添加演示日记」按钮
   - 系统会自动添加一篇演示日记
3. **管理日记**：
   - 点击日记下方的「编辑」按钮，修改日记内容
   - 点击「删除」按钮，删除日记

## 📅 创意日历

### 功能说明

创意日历用于在日历上标记宝宝的重要事件和成长里程碑。

### 使用方法

1. **查看日历**：进入创意日历页面，查看当前月份的日历
2. **切换月份**：
   - 点击「上一月」按钮，查看上一个月
   - 点击「下一月」按钮，查看下一个月
3. **添加事件**：
   - 点击「添加演示事件」按钮
   - 系统会在当前日期添加一个演示事件

## ⏰ 时光轴

### 功能说明

时光轴以时间线的形式展示宝宝的成长里程碑，让您清晰地看到宝宝的成长历程。

### 使用方法

1. **查看时光轴**：进入时光轴页面，浏览宝宝的成长里程碑
2. **添加里程碑**：
   - 点击「添加演示里程碑」按钮
   - 系统会自动添加一个演示里程碑
3. **管理里程碑**：
   - 点击里程碑下方的「编辑」按钮，修改里程碑信息
   - 点击「删除」按钮，删除里程碑

## 👶 宝宝管理

### 功能说明

宝宝管理用于添加和管理宝宝的基本信息，支持管理多个宝宝。

### 使用方法

1. **查看宝宝列表**：进入宝宝管理页面，查看已添加的宝宝列表
2. **添加宝宝**：
   - 点击「添加演示宝宝」按钮
   - 系统会自动添加一个演示宝宝
3. **管理宝宝**：
   - 点击宝宝信息下方的「编辑」按钮，修改宝宝信息
   - 点击「删除」按钮，删除宝宝

## 📊 成长指标

### 功能说明

成长指标用于记录和追踪宝宝的身高、体重、头围等成长数据，帮助您了解宝宝的成长情况。

### 使用方法

1. **选择宝宝**：在下拉菜单中选择要查看的宝宝
2. **查看成长数据**：表格中显示宝宝的成长记录
3. **添加成长记录**：
   - 点击「添加成长记录」按钮
   - 填写成长数据表单
   - 提交表单，添加新的成长记录
4. **管理成长记录**：
   - 点击表格中的「编辑」按钮，修改成长记录
   - 点击「删除」按钮，删除成长记录
5. **查看成长曲线**：点击「查看成长曲线」按钮，查看宝宝的成长趋势

## 🎥 视频管理

### 功能说明

视频管理用于存储和管理宝宝的成长视频，记录宝宝的动态成长过程。

### 使用方法

1. **查看视频**：进入视频管理页面，浏览已有的宝宝视频
2. **上传视频**：
   - 点击「上传视频」按钮
   - 选择要上传的视频文件
   - 系统会模拟上传过程并添加视频
3. **管理视频**：
   - 点击视频下方的「编辑」按钮，修改视频信息
   - 点击「删除」按钮，删除视频

## ⚙️ 设置中心

### 功能说明

设置中心用于个性化系统设置，包括主题、语言、备份等选项。

### 使用方法

1. **主题设置**：
   - 在「主题」下拉菜单中选择「浅色」或「深色」主题
   - 系统会实时切换主题
2. **语言设置**：
   - 在「语言」下拉菜单中选择「简体中文」或「English」
   - 系统会切换界面语言
3. **自动备份**：
   - 勾选「自动备份」复选框，开启自动备份功能
   - 取消勾选，关闭自动备份功能
4. **数据管理**：
   - 点击「导出数据」按钮，导出系统数据
   - 点击「导入数据」按钮，导入之前导出的数据
5. **关于信息**：查看系统的版本信息和相关说明

## 🔄 登录状态

- **登录状态持久化**：登录后，系统会记住您的登录状态
- **刷新页面**：刷新页面后，您仍然保持登录状态，无需重新登录
- **登出**：点击导航菜单中的「登出」按钮，退出登录状态

## 📱 响应式设计

系统采用响应式设计，支持在不同设备上访问：
- **桌面端**：完整的功能和布局
- **平板端**：适配平板屏幕的布局
- **手机端**：适配手机屏幕的布局，优化触摸操作

## 💡 使用技巧

1. **快速访问**：使用顶部导航菜单快速切换到不同功能
2. **演示数据**：使用「添加演示」按钮快速添加演示数据，了解系统功能
3. **数据管理**：定期导出数据，备份宝宝的成长记录
4. **多设备访问**：在不同设备上登录系统，查看宝宝的成长记录
5. **个性化设置**：根据个人喜好调整系统主题和语言

## ❓ 常见问题

### 登录问题
- **忘记密码**：目前系统使用模拟登录，可使用演示账号登录
- **登录失败**：检查用户名和密码是否正确，确保使用演示账号：demo/demo123

### 数据问题
- **数据存储**：系统使用浏览器的本地存储，清除浏览器缓存可能会导致数据丢失
- **数据备份**：定期使用「导出数据」功能备份数据

### 功能问题
- **上传失败**：系统使用模拟上传，实际环境中需要后端服务支持
- **功能限制**：演示版本可能有部分功能限制

如果您在使用过程中遇到任何问题，请联系系统管理员或查看技术文档获取帮助。
