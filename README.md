# BabyMemo - 宝宝成长记录系统

一个基于React + Next.js的宝宝成长记录系统，帮助父母记录宝宝的成长历程。

## ✨ 功能特性

- 🎨 **现代化界面** - 基于Tailwind CSS的响应式设计
- 🔒 **用户系统** - 登录/注册功能（模拟登录，无需后端）
- 📷 **照片墙** - 记录宝宝的美好瞬间
- 📝 **创意日记** - 写下宝宝的成长故事
- 📅 **创意日历** - 记录重要的成长里程碑
- ⏰ **时光轴** - 可视化宝宝的成长历程
- 👶 **宝宝管理** - 管理宝宝信息
- 📊 **成长指标** - 追踪宝宝的身高、体重等指标
- 🎥 **视频管理** - 存储宝宝的成长视频
- ⚙️ **设置中心** - 个性化系统设置
- 🔄 **登录状态持久化** - 刷新后保持登录状态

## 🚀 快速开始

### 环境要求

- Node.js 18.0+
- npm 9.0+

### 安装步骤

1. **克隆项目**

```bash
git clone <repository-url>
cd babymemo
```

2. **安装依赖**

```bash
npm install
```

3. **启动开发服务器**

```bash
npm run dev
```

4. **访问应用**

打开浏览器访问：http://localhost:3000

## 📚 技术栈

- **前端框架**：React + Next.js
- **样式框架**：Tailwind CSS
- **状态管理**：React Context API
- **数据存储**：LocalStorage / SessionStorage
- **构建工具**：Next.js Build
